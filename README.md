# 🏥 Disease Prediction System

A Machine Learning-powered web application that predicts diseases based on user symptoms using a trained Scikit-Learn classification model. The application provides real-time predictions through an interactive Flask web interface.

---

## 🚀 Project Overview

The Disease Prediction System is designed to demonstrate the complete Machine Learning workflow, from data preprocessing and model training to deployment using Flask.

Users can select symptoms such as:

* Fever
* Cough
* Headache
* Fatigue

The system processes the input and predicts the most likely disease using a trained machine learning model.
